# Установка

Монтаж идёт **на вашем компьютере**: расшифровка, вырезание пауз и сборка видео работают локально и бесплатно.
Нужен компьютер с Windows, macOS или Linux, 8+ ГБ памяти (лучше 16), ~5 ГБ свободного места.
Видеокарта NVIDIA не нужна — всё работает на процессоре, просто медленнее.

Проще всего попросить агента: «Установи навык монтажа по install/УСТАНОВКА.md» — он сделает шаги сам
и спросит только то, что нужно от вас.

## 1. Программы

| Что | Зачем | Windows | macOS |
|---|---|---|---|
| ffmpeg | резать и склеивать видео | `winget install Gyan.FFmpeg` | `brew install ffmpeg` |
| Python 3.11+ | расшифровка, чистка, скрипты | `winget install Python.Python.3.12` | `brew install python@3.12` |
| Node.js 20+ | движок Remotion (графика из кода) | `winget install OpenJS.NodeJS.LTS` | `brew install node` |

После установки на Windows закройте и откройте консоль заново, чтобы программы стало видно.
Проверка: `ffmpeg -version`, `python --version`, `node --version`.

## 2. Положить навык на место

| Где работаете | Куда положить папку `reels-montazh` |
|---|---|
| **Claude Code** | `~/.claude/skills/reels-montazh/` (для всех проектов) или `<проект>/.claude/skills/reels-montazh/` (для одного) |
| **Codex** (CLI / приложение) | `~/.codex/skills/reels-montazh/` (для всех) или `<проект>/.codex/skills/reels-montazh/`. Если ваша версия Codex ищет навыки в другом месте — посмотрите раздел Skills в документации Codex |
| **Claude на сайте** (claude.ai) | Настройки → Customize → Skills → «+» → Upload a skill → выбрать **лёгкий** архив `reels-montazh-для-сайта.zip` (без звуков и анимаций — полный архив слишком тяжёлый для загрузки). Нужно включить выполнение кода. Ограничение — ниже |

`~` — это папка пользователя (в Windows `C:\Users\<имя>`). Папку навыка лучше **не класть в OneDrive / Dropbox**:
в движке тысячи мелких файлов, синхронизация их замучает.

**Про сайт claude.ai.** Там навык работает в облачной песочнице: в ней нельзя поставить ffmpeg-сборку видео,
Remotion с браузером и модели на гигабайты, а ролики с телефона слишком тяжёлые для загрузки. На сайте навык
полезен как помощник по планированию: хуки, чистка текста расшифровки, выжимка по прогреву, раскадровка,
тексты карточек, подсказки для картинок. Сам монтаж — в Claude Code или Codex на своём компьютере.

## 3. Поставить зависимости

Из папки навыка:

- Windows: `powershell -ExecutionPolicy Bypass -File install\setup.ps1`
- macOS / Linux: `bash install/setup.sh`

Скрипт создаёт отдельное окружение Python (`~/.montazh-venv`), ставит библиотеки из `requirements.txt`,
движок Remotion (`npm ci` в `remotion/`, ~800 МБ), скачивает модель для «слова за спикером» (15 МБ)
и составляет список звуков. При первой расшифровке сама скачается модель Whisper (~1,6 ГБ), при первой сборке
Remotion — свой браузер (~100 МБ). Нужен интернет только на эти разы.

Все скрипты дальше запускаются этим Python: `~/.montazh-venv/Scripts/python.exe` (Windows)
или `~/.montazh-venv/bin/python` (macOS / Linux).

## 4. Рабочая папка с видео

В папке, где будут лежать ролики (например, папка проекта):

```
<python навыка> <папка навыка>/scripts/init.py
```

Появится `монтаж/` с папками «Входящие», «исходники», «Рабочие файлы», «Готовые» и файлами `настройки.toml`,
`прогрев.md`, `просмотр.html`. Скрипт проверит установку и покажет, чего не хватает (строки с ✗).
Заполните в `настройки.toml` раздел `["автор"]` (подпись на карточках) и, если нужно, `прогрев.md`.

## 5. Звуки и анимации

Уже внутри навыка, ставить ничего не нужно:
- `remotion/public/sfx/` — 230 звуков появления графики (вжухи, хлопки, щелчки, разгоны, интерфейс),
  что где — в `remotion/public/sfx/README.md`;
- `assets/glass/` — пак «жидкое стекло»: шаблоны Premiere / After Effects и видео-превью как образцы для кода.

Свои звуки можно добавить в `remotion/public/sfx/` и запустить `<python навыка> scripts/sfx_index.py`.

## 6. Проверка

Положите короткое видео (30–60 с, человек говорит в камеру) во «Входящие» и напишите агенту:
«Смонтируй ролик <название>». Агент сделает расшифровку, черновик и покажет его.
