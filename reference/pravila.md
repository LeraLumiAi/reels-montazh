# Правила качества и работы — для всех стилей

## Как работать с человеком

- Говорить простым языком, без технических терминов; неизбежный термин — объяснить одной фразой.
- Всё ставить и запускать самому; от человека — только то, что может сделать только он (согласие, вход, оплата).
- **Без «да» ничего не пересобирать и не перезаписывать.** Правка общего кода → пересобрать только тот ролик,
  на который жаловались. Не писать в файл, который человек сейчас смотрит.
- Перед монтажом — 2–3 варианта хука на выбор. После финала — сразу дубль для ТикТока.
- Подсказки для картинок и видео в нейросетях — прямо в чат блоками кода, по одной.
- Числа в отчёте («готово 5 роликов») — пересчитать по папке, а не по памяти.
- Называть точную папку и файл; отличать «исходник» от «готового ролика».

## Ничего на лице

Ни плашки, ни субтитры, ни надписи не ложатся на лицо — ни в одном формате. Над головой нет места — карточка вниз
на место субтитров. Под лицом нет места — субтитры убрать. Место считать от реального лица в этом ролике
(`лицо.json`, макушка из `макушка.json`), а не брать числа из прошлого ролика.

## Зоны интерфейса Instagram (кадр 1080×1920)

| Зона | Где |
|---|---|
| Шапка «Reels · Друзья» | сверху до ~245 px (в коде запас — 270) |
| Кнопки лайк / комментарий / поделиться | справа, x ≥ 920, начиная с y ≈ 1200–1235 |
| Ник, подпись, музыка | снизу, примерно с y ≈ 1740 (запас в коде — нижние 460 px) |
| Обрезка краёв на вытянутых телефонах | по ~51 px слева и справа (поле в коде — 110) |

Числа заданы в профиле стиля (`instagram` в `remotion/src/styles/warmLight.ts`).

## Проверка кадров перед показом

1. Снять кадры: `npx remotion still …` или `ffmpeg -ss <t> -i ролик.mp4 -frames:v 1 кадр.png` — на каждой карточке,
   слове за спикером и паре обычных мест.
2. Наложить зоны Instagram красными прямоугольниками (`ffmpeg -vf drawbox=…`) и смотреть с ними.
3. На каждом кадре отдельно: лицо открыто; низ каждой плашки выше макушки или плашка внизу;
   ничего не заходит на кнопки, шапку, ник; нет строки из одного короткого слова и переноса там, где строка не полная.
4. Субтитр совпадает с голосом (проверить 2–3 места на слух / по времени слов).

## Показ ролика

- Делать копию «… — для просмотра.webm» (на части компьютеров mp4 1080×1920 в окне просмотра полосит).
- В Claude Code (приложение) — открыть сбоку через встроенный браузер: `templates/просмотр.html?f=<путь к webm>`,
  запущенный через локальный сервер (адрес `file://` у некоторых не нажимается). Проверить, что видео играет:
  `video.error` пусто, `currentTime` растёт после `play()`.
- Если просмотрщика нет — назвать путь к файлу; публиковать — mp4 из «Готовых».

## Технические

- Финал: MP4 H.264 High 4.1, 1080×1920, ровно 30 к/с, yuv420p, bt709, AAC 48 кГц, faststart.
- Ручной render — всегда с `--pixel-format=yuv420p --color-space=bt709`.
- Расшифровку не переделывать без нужды: повторный монтаж её не требует.
- Длинное вырезание человека (`matte.py`): компьютер не должен засыпать.
