# Скрипты и файлы ролика

Все скрипты — в `scripts/`, запускаются Python из окружения навыка (см. `install/УСТАНОВКА.md`).
Видео передаётся путём к файлу; рабочая папка ролика — `Рабочие файлы/<имя файла без расширения>/`.
Рабочая папка с видео ищется как описано в `scripts/paths.py` (переменная `MONTAZH_WORK` или ближайшая
папка с `настройки.toml`). В Windows-консоли для кириллицы нужно `PYTHONIOENCODING=utf-8`.

## Порядок

```
init.py [папка]                 один раз: рабочая папка + проверка установки
transcribe.py <видео>           расшифровка.json / .txt — слова со временем (faster-whisper large-v3-turbo, повторно не делает)
cleanup.py <видео>              чистка.json / чистка.txt — паузы (по звуку), паразиты, вырезки из правки.json и подгонка.json
phrases.py <видео>              фразы с номерами слов + кандидаты в дубли → Claude пишет правки.json
fit.py <видео> [--до 90]        подгонка под лимит: ускорение до «предела», дальше Claude выбирает слабые куски
build.py <видео> [--черновик]   <тема> — чистый.mp4 (1080×1920, 30 к/с) или черновик 540×960
timeline.py <видео>             слова_чистые.json — время слов в чистом ролике, склейки
subtitles.py <видео> [--заново] субтитры.json — фразы по 2–4 слова; Claude ставит «ключ» и правит «разрывы»
face.py <видео>                 лицо.json — где лицо (OpenCV), сам вызывается из overlay.py
matte.py <видео> [--куски …]    человек.webm — человек без фона для слова за спикером (сам вызывается из overlay.py)
storyboard.py <видео>           раскадровка.html — план ролика (сам вызывается из overlay.py)
overlay.py <видео> [--тест [с]] [--черновик]   оформление через Remotion → тест / черновик / «Готовые/<тема>.mp4»
dub.py <видео> --от <н> [--убрать н,н] [--имя ТикТок]   дубль без призыва → потом overlay.py по новому исходнику
polovina.py <видео> [--черновик] [--тикток] [--сдвиг 150] [--шов 1280]   формат «полэкрана»
sfx_index.py                    список звуков в remotion/public/sfx/ (после того как добавили звуки)
```

Если ролик поменялся после чистки — заново `build.py` → `timeline.py` → `subtitles.py` (`--заново` сохраняет
выбранные ключевые слова и исправленные написания).

## Файлы, которые правит Claude

| Файл | Что | Формат |
|---|---|---|
| `правки.json` | что вырезать: дубли, оговорки, просьбы человека | `{"вырезать_слова": [{"с": 219, "по": 221, "почему": "дубль: …"}]}`; точный край — `"от_секунды"` / `"до_секунды"`. Причина «просьба: …» в раскадровке пишется как «по вашей просьбе» |
| `подгонка.json` | лимит, скорость, вырезки для лимита | `{"лимит", "скорость", "вырезать_слова", "режим": "смысловая выжимка"}` |
| `субтитры.json` | фразы, ключевые слова, написания | `"т"` — как слово на экране, `"ключ"` — номер выделенного слова, `"разрывы": {"перед": [н], "не_перед": [н]}` |
| `карточки.json` | карточки по номерам слов | см. `styles/teplyj-svet.md`; `"хвост"` — сколько секунд держать последний кадр |

## Правила чистки и выжимки

- Дубли и оговорки ищет **Claude по смыслу**, не программа: простой поиск путает их с намеренными повторами
  («возьми ручку… возьми ручку»). Остаётся последний удачный вариант.
- Выжимка — как продюсер, по `прогрев.md`: оставить крючок, разрыв шаблона, доверие и экспертность,
  истории «было → стало», тёплые фразы, обещание рассказать подробнее, концовку и призыв. Убрать повторы одной мысли,
  пересказы, путаные начала. Длина — результат, а не цель. Если режем больше пары повторов — сначала показать список.
- **Никогда не резать:** главную мысль, обещание рассказать подробнее, концовку, ведущую к призыву, сам призыв.
- Речь не ускоряется, если не попросили (1,2 уже звучит быстро). Короче 60 с не сокращаем.
- Своих слов в речь не добавить — нужную мысль можно дать карточкой.

## Сборка вручную (образцы форматов)

```
cd <навык>/remotion
npx remotion render src/index.ts <Композиция> "<выход>.mp4" --props="<props>.json" \
  --codec=h264 --audio-codec=aac --pixel-format=yuv420p --color-space=bt709 --crf=16
```
Без `--pixel-format=yuv420p --color-space=bt709` получается «полный диапазон» цвета, и встроенный просмотрщик
его не играет. Видео и звуки для композиции кладутся в `remotion/public/` и берутся через `staticFile`.
Копия для просмотра: `ffmpeg -i X.mp4 -vf scale=540:-2,format=yuv420p -c:v libvpx-vp9 -b:v 2M -color_range tv -c:a libopus X — для просмотра.webm`.

## Тонкости, найденные на практике

- faster-whisper сам читает звук с ошибкой `metadata_errors` — звук подаётся через ffmpeg (так и сделано).
- `vad_filter=True` обязателен: без него Whisper терял куски речи на стыках и выдумывал фразы в тишине.
- Паузы ищутся по звуку (ffmpeg silencedetect): Whisper растягивает слова на соседнюю тишину.
- Видео с телефона бывает 1280×720 с поворотом на 90° — ffmpeg поворачивает сам, `build.py` предупреждает о малом размере.
- В FFmpeg 8 вместо `-filter_complex_script` пишется `-/filter_complex <файл>`.
- В PowerShell не обрезать вывод скриптов через `| Select-Object -First N` — это обрывает программу.
- Готовый файл подменяет старый только целиком (`swap_in`): не писать в файл, который человек сейчас смотрит.
