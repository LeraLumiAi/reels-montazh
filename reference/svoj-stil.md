# Как сделать свой стиль

Стиль — это профиль с цветами, шрифтами, размерами и границами. Остальная система его не знает,
поэтому новый стиль добавляется рядом, ничего не ломая.

## 1. Описать словами

Заполнить с человеком (можно по его брендбуку или паре скриншотов):

```markdown
# Стиль «Название»
Настроение: …  (что можно и чего нельзя: «без неона», «без тёмно-синего»)
Аудитория: …   (возраст, смотрит с телефона?)
Цвета: фон …, текст …, приглушённый …, акцент …, (тёмная и светлая тема)
Шрифты: основной … (с кириллицей!), акцентный …
Подпись автора на карточках: …
Изюминка: …   (точка света, зерно, рамка…)
```

## 2. Профиль в коде

1. Скопировать `remotion/src/styles/warmLight.ts` в `remotion/src/styles/<имя>.ts`, поменять `name` и значения.
2. Добавить в `remotion/src/styles/index.ts`: `import {<имя>} from './<имя>';` и строку в `styles`.
3. Новые шрифты: `npm i @fontsource/<шрифт>` в папке `remotion`, подключить в `remotion/src/fonts.ts`
   (и дождаться загрузки там же). Для замера ширины субтитров добавить файлы шрифта в `scripts/textwidth.py`.
4. В `настройки.toml`: `["оформление"] "стиль" = "<name из профиля>"`.
5. Собрать тест стиля: `overlay.py <видео> --тест` и показать человеку.

## 3. Что делать с прогревом

`templates/прогрев.md` → скопировать в рабочую папку и заполнить: продукт, боли зрителя, подарок за слово
в комментариях. Его Claude читает перед выжимкой и карточкой «дата».
