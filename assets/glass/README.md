# Анимации «жидкое стекло» (Liquid Glass)

- `шаблоны/` — исходный пак: 9 плашек с именем `Liquid Glass Lower Third *.mogrt` и набор `Liquid Glass UI Kit.mbr`.
  Это шаблоны Premiere Pro / After Effects: в Remotion напрямую не вставляются. Их можно открыть в Premiere,
  если монтируете там.
- `образцы/` — 24 коротких видео-превью: стеклянные кнопки, уведомление, плеер, круглые иконки ♥ / ☾ / ✓ / ✕ / лайк,
  переключатель, линза-переход (горизонтальный, вертикальный, квадрат), плашки с именем.

**Как агенту ими пользоваться:** смотреть превью из `образцы/` (кадры через ffmpeg) и повторять движение и вид
в коде Remotion — размытие фона (`backdropFilter: blur`), светлая кромка, блик, пружинное появление.
Стекло ставится только поверх фото или видео — на пустом фоне оно не читается.
Звуки к стеклу — `remotion/public/sfx/glass/`.
