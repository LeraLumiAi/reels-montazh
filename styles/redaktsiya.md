# Стиль «Редакция» — монохромная типографика

**Когда:** нейтральный ролик не в фирменном стиле автора: свои голосовые, ролики учеников, «покажи что-то новое».
Можно начать с ИИ-клипа (видео из нейросети) и перейти в графику. Без лица или с коротким вступлением.
**Движок:** образец `remotion/src/formats/Neutral.tsx` (композиция `Neutral`, пропсы `intro` / `introEnd` — клип в начале,
`audio`, `words`). Сцены — под конкретный ролик, приёмы (`Words`, `Scene`, `Art`, `Lbl`) переиспользуются.

## Как выглядит

- Палитра: тёплая серая бумага #ECEAE5, чёрный #111, серый #8C8A85, линии #CFCCC5. Без золота, без Playfair,
  без подписи автора. Шрифт — Onest.
- Тонкая сетка и счётчик сцен «01 / 11».
- Слова выезжают из-под маски ровно в момент звучания; ключевые — в чёрной плашке.
- Сцена каждые 2–3 с, появляется шторкой снизу; часть сцен — инверсия (чёрный фон).
- Простая геометрия-метафора: батарейка разряжается, квадрат не проходит в круг, штамп «ДА»,
  перечёркнутое слово, волна, слово рассыпается на буквы. Одна мысль — одна фигура.
- Звуки на каждую смену (вжух) и на удары/штампы — из `remotion/public/sfx/` (`Whooshes/`, `Riser/`, `ui/`).

## Порядок

1. `transcribe.py` по голосу (или по ролику), при желании чистка.
2. Раскадровка: «фраза → метафора → подпись заглавными». Показать, принять правки.
3. Копия образца, сцены по номерам слов. ИИ-клип — в `remotion/public/<тема>/`, проп `intro`.
4. Ручной render с `--pixel-format=yuv420p --color-space=bt709`, копия webm для просмотра.
