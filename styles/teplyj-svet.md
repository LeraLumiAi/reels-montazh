# Стиль «Тёплый свет» — говорящая голова (основной формат)

**Когда:** обычный Reels / Shorts / TikTok, где человек говорит в камеру. Вертикаль 1080×1920, 30 к/с.
**Движок:** композиция `Reel` (`remotion/src/Reel.tsx`), собирает `scripts/overlay.py`. Код под ролик не меняется —
всё задаётся файлами в `Рабочие файлы/<тема>/` (субтитры.json, карточки.json и т. д.).
**Профиль стиля:** `remotion/src/styles/warmLight.ts`. Свой стиль — по `reference/svoj-stil.md`.

## Как выглядит

- Настроение: утренний свет, спокойствие, много воздуха. Без космоса, звёзд, тёмно-синего, неона, оливковых оттенков.
- Палитра для видео (тема «Вечер»): фон #2A221D / #362C26 / #4A3D34; текст #F3EAE0, приглушённый #BFAE9E;
  акцент и свечение #E0BE7A; карамель #D4A983. Светлые карточки (тема «Утро»): фон #F7F2EA, текст #3A332E, акцент #7E5A2E.
  Золото — только свечение и ореол, не заливка и не цвет больших надписей.
- Шрифты: Onest (600 — заголовки и субтитры, 400 — текст, 500 — подписи заглавными с разрядкой),
  Playfair Display Italic — только курсивные акценты, 1–3 слова на фразу. Оба с кириллицей, ставятся из npm.
- Аудитория смотрит с телефона: субтитры 64 px, ничего мельче 46 px на кадре 1080.

## Что делает каждый приём

| Приём | Как | Правила |
|---|---|---|
| Субтитры-плашки | 2–4 слова на «матовом стекле» (#2A221D 55 %, размытие 18, скругление 36), центр y≈1380 | Звучащее слово светлое, остальные приглушены; ключевое — Playfair Italic золотым, примерно в половине фраз. Строка не кончается на «и», «в», «на», «своему». Без точек и запятых на конце, «?» и «!» остаются |
| Смена плана | На склейках средний ↔ крупный (×1,22), между ними очень медленный наезд (+0,6 %/с) | Не чаще раза в 10 с. Лицо на 40 % высоты кадра, по центру. Подбородок на экране не ниже ~1290 px |
| Карточки по смыслу | Примерно раз в 10 с (настройка `плотность_графики`) | Тексты — из слов спикера, без выдуманных обещаний, не больше ~10 слов. Над головой, если хватает места; нет — **вниз на место субтитров**, субтитры на это время прячутся |
| Слово за спикером | Огромное слово заглавными кремовым позади головы, голова закрывает низ букв | 1–2 раза за ролик, на самых важных словах. Слово — **в той форме, как сказано** («пути», а не «путь»). Лучше до ~8 букв. Камера на нём держит средний план. Нужна модель (см. установку) |
| Заголовок в начале и призыв в конце | Предлагаются в раскадровке | Человек решает, ставить ли |
| Переходы | Мягкое затухание 300–400 мс | — |

## Карточки (`карточки.json`)

Пишет Claude по номерам слов (`phrases.py` / `слова_чистые.json`). `*звёздочки*` — курсив, `\n` — новая строка.

| Тип | Когда ставить | Поля |
|---|---|---|
| `заголовок` | крючок ролика в начале | `подпись`, `крупно` (главное и цифра огромным курсивом), `текст` |
| `шаг` | истории и пункты по порядку («Случай из практики · 1 …») — вся серия оформляется одинаково, плашка не мигает | `подпись`, `цифра`, `слово` |
| `бейдж` | имя, факт о человеке | `подпись`, `главное`, `ниже` |
| `цитата` | тёплая фраза, которую хочется пересказать (дословно) | `текст`, `автор`, `тема`, `стекло` |
| `слово` | одно главное слово ролика на весь экран, сквозь буквы видно спикера; не больше одного на ролик | `слово`, `подпись`, `размер`, `y` |
| `экран` | экран, залитый цветом, с фразой | `текст`, `цвет`, `подпись`, `размер` |
| `список` | перечисление 2–4 пунктов, пункты появляются, когда их называют | `подпись`, `заголовок`, `пункты: [{т, слово}]`, `тема` |
| `дата` | продукт / событие / скидка из `прогрев.md` — там, где спикер обещает рассказать подробнее | `месяц`, `число`, `подпись`, `заголовок`, `ниже` |
| `призыв` | в конце: слово в комментарии + превью подарка | `подпись`, `заголовок`, `ниже`, `гайд: {цифра, текст}` |
| `за спикером` | слово за головой | `слово`, `вид` (по умолчанию заглавные; `курсив`, `контур` — запасные) |

У каждой карточки `от` и `до` — номера слов. Правила: две одинаковые карточки подряд не ставить; карточка — на фразе,
а не между фразами; цифра рядом с курсивом — тем же курсивом; точку в конце крупных надписей не ставить.
Переносы `\n` — только чтобы строки вышли примерно равными; строки из одного короткого слова не оставлять.

Пример:
```json
{"карточки": [
  {"тип": "заголовок", "от": 0, "до": 8, "подпись": "Ваша подпись", "крупно": "3 вопроса", "текст": "которые *стоит* задать себе"},
  {"тип": "список", "от": 9, "до": 22, "подпись": "Упражнение", "заголовок": "Возьми *ручку*",
   "пункты": [{"т": "Посмотри", "слово": 11}, {"т": "Потрогай", "слово": 15}, {"т": "*Вспомни*", "слово": 17}]},
  {"тип": "за спикером", "от": 74, "до": 75, "слово": "ЧУВСТВА"},
  {"тип": "призыв", "от": 89, "до": 106, "подпись": "Подарок", "заголовок": "Напиши\n*«Слово»*",
   "ниже": "в комментариях —\nпришлю гайд", "гайд": {"цифра": "7", "текст": "шагов\nк *цели*"}}
]}
```

## Порядок работы над роликом

1. Предложить 2–3 варианта **хука** на первые секунды (из слов спикера) — человек выбирает.
2. `transcribe.py` → `cleanup.py` → `phrases.py` → Claude по смыслу пишет дубли и оговорки в `правки.json`
   (намеренные повторы оставить) → при лимите или просьбе «выжимка» — `fit.py` и разбор как продюсер по `прогрев.md`
   → `build.py --черновик`. Показать черновик, принять правки.
3. `build.py` → `timeline.py` → `subtitles.py` (Claude выбирает ключевые слова и чинит разрывы) →
   `карточки.json` → `overlay.py --черновик` (сам обновит раскадровку). Показать раскадровку и черновик сбоку.
4. Тест стиля на 30 с при новых правках оформления: `overlay.py --тест [секунда]`.
5. После «да» — `overlay.py` (финал в «Готовые») и сразу **дубль для ТикТока**:
   `dub.py <видео> --от <н>` → `overlay.py "исходники/<тема> — ТикТок.mp4"`. Призыв «напиши в комментариях»
   вырезается, фраза перед ним должна остаться законченной; в конце карточка из `["тикток"]` настроек и «хвост» 1,5 с.

Подробно о скриптах и файлах — `reference/pipeline.md`. Проверка кадров перед показом — `reference/pravila.md`.

## Сколько ждать (ноутбук без NVIDIA)

- расшифровка ≈ 20 с на минуту видео;
- черновик с карточками ≈ 1 мин на минуту ролика; финал ≈ 1,5–2,5 мин на минуту;
- слово за спикером в первый раз — вырезание человека ≈ 6 мин на минуту ролика (с `--куски` — только нужные места).
  Компьютер не должен засыпать.
