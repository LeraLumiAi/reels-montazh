# Стиль «Голос и графика» — без лица, только голос и анимация

**Когда:** закадровый голос (голосовое, озвучка), спикера в кадре нет — ролик держится только на графике.
**Движок:** два образца:
- вертикаль 1080×1920 — `remotion/src/formats/VoiceGraphic.tsx` (композиция `Grafika`, проп `theme`: «Утро» / «Вечер»);
  в нём же набор приёмов, которыми пользуются другие форматы;
- горизонталь 16:9 — `remotion/src/formats/Kosmos.tsx` (композиция `Kosmos`): тёмный фон, тонкая светящаяся
  линейная графика.

Сцены в образцах — под конкретный ролик (номера слов). Для нового ролика — копия образца и свои сцены.

## Главное правило: динамика

Ролик без лица держится только на смене картинки. Спокойные сцены по 10 секунд смотреть скучно — зритель уходит.
- Смена кадра каждые **2–3 с** (в горизонтали — 1,5–3 с): картинка с наездом/параллаксом → крупное слово → картинка.
- Картинка **буквально иллюстрирует фразу** (говорят «ступени» — рисуются ступени 1-2-3).
- Кинетический текст: слова появляются в момент, когда звучат.
- Переход-вжух со звуком на каждой смене, звуки разнообразить, один и тот же подряд не повторять.
- Постоянный «якорь» (кольцо-солнце, портал сверху) пульсирует на сменах — связывает ролик.
- Перед началом попросить у человека референсы и посмотреть их.

## Как выглядит

- **Вертикаль:** цвета и шрифты профиля стиля, Onest + курсив Playfair для 1–3 слов, скругления 20/36/пилюля,
  плёночное зерно, подпись автора слева сверху ниже шапки Instagram. Движение: пружины с отскоком, проявление
  из размытия, уход сцены с размытием, печать текста, «виджеты»-карточки, уведомления, календарь.
  Стекло — только поверх фото или видео; образцы движения — `assets/glass/образцы/`. Звуки — `remotion/public/sfx/`.
- **Горизонталь 16:9:** почти чёрный тёплый фон, линии-созвездия из точек, контурные фигурки, глаз, ворота,
  ступени; цифры нарисованы точками и линиями; субтитры 2 строки внизу мелко (серые, ключевое слово белым жирным);
  в конце кнопка-пилюля с призывом.

## Порядок

1. Голос → `transcribe.py` (если нужно — чистка как в основном стиле, речь можно ускорить до 1,2 по просьбе).
2. Раскадровка: таблица «фраза → картинка → звук», смена каждые 2–3 с. Показать, принять правки.
3. Копия образца, сцены по `w(н)`. Голос — в `remotion/public/<тема>/`, проп `audio`.
4. Ручной render с `--pixel-format=yuv420p --color-space=bt709`, копия webm для просмотра.
