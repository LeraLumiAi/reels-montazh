# Монтаж Reels с агентом

Превращает запись с телефона в готовый вертикальный ролик 1080×1920. Человек говорит обычными словами
(«смонтируй ролик…», «убери карточку 3», «собирай»), агент запускает скрипты и правит файлы ролика.
Всё работает локально: Whisper (расшифровка), FFmpeg (нарезка), Remotion (графика из кода).

## Стили — какой когда

| Стиль | Когда использовать | Файл |
|---|---|---|
| **Тёплый свет** (основной) | человек говорит в камеру; субтитры-плашки, смена плана, карточки, слово за спикером | [styles/teplyj-svet.md](styles/teplyj-svet.md) |
| **Полэкрана** | говорящая голова + объяснение картинкой: спикер сверху, анимация на стекле снизу | [styles/polekrana.md](styles/polekrana.md) |
| **Конспект** | обучающий ролик с разделами и пунктами: бумага с картинками и схемами от руки | [styles/konspekt.md](styles/konspekt.md) |
| **Голос и графика** | спикера в кадре нет, только голос; вертикаль или горизонталь 16:9 | [styles/golos-i-grafika.md](styles/golos-i-grafika.md) |
| **Редакция** | нейтральный монохромный ролик не в фирменном стиле; можно начать с ИИ-клипа | [styles/redaktsiya.md](styles/redaktsiya.md) |

Стиль не назван — «Тёплый свет» (или тот, что указан в `настройки.toml`). Открывай файл выбранного стиля
перед работой. «Тёплый свет» собирается целиком из файлов ролика; остальные — **образцы**: сцены в них
привязаны к словам конкретного ролика, для нового ролика агент копирует образец и пишет сцены заново.

## Порядок работы над роликом

1. Видео во `Входящие` → назвать файл по теме (предложить название по началу расшифровки) → перенести в `исходники/`.
2. Предложить 2–3 **хука** на первые секунды из слов спикера, дождаться выбора.
3. Расшифровка → чистка → дубли и оговорки по смыслу → (выжимка по `прогрев.md`, если просили) → **черновик**. Показать.
4. Субтитры, карточки / сцены → **раскадровка** и **черновик с оформлением**. Показать, править словами.
5. После «да» — **финал** в `Готовые/` и сразу **дубль для ТикТока**.

Скрипты, файлы ролика и их форматы — [reference/pipeline.md](reference/pipeline.md).
Правила качества (ничего на лице, зоны Instagram, проверка кадров, показ) — [reference/pravila.md](reference/pravila.md).
Свой фирменный стиль — [reference/svoj-stil.md](reference/svoj-stil.md).

## Главные правила

- Без «да» человека ничего не пересобирать и не перезаписывать; не писать в файл, который он смотрит.
- Ничего не класть на лицо. Перед показом смотреть кадры с наложенными зонами Instagram.
- Никогда не вырезать главную мысль, обещание рассказать подробнее и призыв. Речь не ускорять без просьбы.
- Тексты на экране — из слов спикера; слово за спикером — в той форме, как сказано.
- Говорить с человеком просто, без технических терминов. Подсказки для нейросетей — в чат блоками кода.

## Что нужно для работы

| Что | Версия | Зачем |
|---|---|---|
| ffmpeg | 6+ (проверено на 8/9) | нарезка, склейка, перекодирование |
| Python | 3.11+ | скрипты; библиотеки — [install/requirements.txt](install/requirements.txt): faster-whisper, numpy, opencv-python-headless, fonttools, Brotli, onnxruntime |
| Node.js | 20+ | Remotion 4 (`remotion/package.json`): графика из кода, шрифты Onest и Playfair Display из npm |
| Модель Whisper large-v3-turbo | скачивается сама, ~1,6 ГБ | расшифровка русской речи |
| Модель RVM mobilenetv3 | 15 МБ, [models/README.md](models/README.md) | вырезание человека для слова за спикером (необязательно) |
| Звуки | 230 шт., уже внутри: [remotion/public/sfx/README.md](remotion/public/sfx/README.md) | звуки появления графики в образцах форматов |
| Анимации стекла | уже внутри: [assets/glass/README.md](assets/glass/README.md) | образцы движения «жидкое стекло» |

Видеокарта не нужна. 8+ ГБ памяти, ~5 ГБ на диске.

## Установка

Подробно — [install/УСТАНОВКА.md](install/УСТАНОВКА.md). Коротко:

- **Claude Code:** папку навыка — в `~/.claude/skills/reels-montazh/` → из неё `install\setup.ps1` (Windows) или
  `bash install/setup.sh` → в папке проекта `<python навыка> <навык>/scripts/init.py`.
- **Codex:** то же, но папка — `~/.codex/skills/reels-montazh/` (или `.codex/skills/` в проекте).
- **Claude на сайте:** Customize → Skills → «+» → Upload a skill → лёгкий `reels-montazh-для-сайта.zip` (нужно выполнение кода).
  В облаке монтаж видео не запускается — там навык помогает с хуками, выжимкой, раскадровкой и текстами карточек.

Если `init.py` показывает строки с ✗ — сначала доустановить то, что в них написано.

## Где что лежит

```
reels-montazh/
  SKILL.md            это оглавление
  styles/             по файлу на стиль
  reference/          скрипты и файлы, правила качества, свой стиль
  scripts/            Python: расшифровка, чистка, сборка, субтитры, лицо, маска, раскадровка, дубль
  remotion/           движок графики: src/Reel.tsx (основной), src/formats/ (образцы), src/styles/ (профили стилей)
  templates/          настройки.toml, прогрев.md, просмотр.html, памятка «Как пользоваться» — копируются в рабочую папку
  install/            установка: УСТАНОВКА.md, requirements.txt, setup.ps1, setup.sh
  models/             модель для слова за спикером (скачивается)
  assets/glass/       анимации «жидкое стекло»: шаблоны и видео-превью
  remotion/public/sfx/  230 звуков появления графики
```

Рабочая папка с видео (`монтаж/`) живёт отдельно от навыка; её путь — `MONTAZH_WORK` или ближайшая папка
с `настройки.toml` (см. `scripts/paths.py`).
