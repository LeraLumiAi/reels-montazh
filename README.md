# reels-montazh — монтаж Reels с ИИ-агентом

Навык для **Claude Code** и **Codex**: превращает запись «говорящей головы» с телефона в готовый вертикальный
ролик 1080×1920 — командами на русском, на своём компьютере, бесплатно.

## Что умеет

- Расшифровка речи со временем каждого слова (Whisper, локально).
- Чистка: паузы, «э-э», слова-паразиты, оговорки и неудачные дубли.
- Смысловая выжимка «как продюсер» и подгонка под лимит длины.
- Субтитры-плашки с подсветкой звучащего слова и ключевыми словами курсивом.
- Смена плана (средний ↔ крупный) с медленным наездом, лицо всегда в кадре.
- Карточки по смыслу: заголовок, номер пункта, цитата, список, календарь, призыв с подарком.
- Огромное слово за спиной спикера (человек вырезается из фона автоматически).
- Раскадровка, черновик, тест стиля, финал и версия для ТикТока.
- Пять стилей: «Тёплый свет», «Полэкрана», «Конспект», «Голос и графика», «Редакция» — и свой.
- 230 звуков появления графики и пак анимаций «жидкое стекло» внутри.

## Как поставить

1. Скачайте архив из раздела **[Releases](../../releases)**:
   - `reels-montazh.zip` — полный, для Claude Code и Codex;
   - `reels-montazh-site.zip` — лёгкий, для загрузки на claude.ai (там навык помогает с планированием, но не монтирует).
2. Распакуйте в `~/.claude/skills/` (Claude Code) или `~/.codex/skills/` (Codex).
3. Поставьте ffmpeg, Python 3.11+, Node.js 20+ и запустите установщик из папки навыка:
   `install\setup.ps1` (Windows) или `bash install/setup.sh` (macOS / Linux).

Подробно — [install/УСТАНОВКА.md](install/УСТАНОВКА.md). Как работает навык и какой стиль когда — [SKILL.md](SKILL.md).

Проще всего — попросить агента: «Установи навык монтажа по install/УСТАНОВКА.md».

## Что внутри

| Папка | Что |
|---|---|
| `SKILL.md` | оглавление для агента: стили, порядок работы, правила |
| `styles/` | по файлу на стиль |
| `reference/` | скрипты и файлы ролика, правила качества, свой стиль |
| `scripts/` | Python: расшифровка, чистка, сборка, субтитры, раскадровка, дубль |
| `remotion/` | движок графики (Remotion) и звуки в `public/sfx/` |
| `assets/glass/` | анимации «жидкое стекло» |
| `templates/` | настройки, прогрев, памятка для человека |
| `install/` | установка |

Модель для «слова за спикером» — [Robust Video Matting](https://github.com/PeterL1n/RobustVideoMatting) (GPL-3.0), скачивается при установке.
